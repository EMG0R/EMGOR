DemiurgeOS: A Thoughtfully Designed System for DSP on the Raspberry Pi

Emory Smith · Ilai Gilbert · Ajay Kapur

California Institute of the Arts

Draft — Linux Audio Conference target · system running today

Abstract

DemiurgeOS is a flashable, audio-first operating system for the Raspberry Pi 5 — a modern successor to Stanford CCRMA's Satellite. Every major audio language ships pre-installed and pre-wired — Csound, Pure Data, SuperCollider, ChucK, Faust, Strudel, C++, Python — routed through a unified PipeWire abstraction and tempo-locked to a global clock. Programs never see hardware: everything moves through one virtual sink and one shared MIDI bus, so hot-plug is invisible and a second interface aggregates automatically. The whole system is driven from a single hot-reloaded config file. Edit one file, reboot, perform.
