Open-Pedal: An Accessible System for Modularly Creating Guitar Pedals and Synthesizers

Emory Smith

EMGOR / California Institute of the Arts

Draft — NIME 2027 target

Abstract

The goal of this project is to support disruption of the hold capitalism has on digital instruments and DSP through an open-source, DIY framework for creating powerful instruments and effect processors. The modularity of the system allows people to pay for only the sensors and compute they need while providing a simple path toward making powerful digital interfaces with our thoughtfully designed PCBs, software (Arduino IDE fork with example programs and preinstalled libraries) and interactive guides.

Keywords: open source hardware, DIY, guitar pedals, PCB design, accessibility, DSP education

1. Introduction

With the rising accessibility of coding, engineering, and technology overall, this framework contributes to bridging the gap between high-value electronics and the general population. Commercial digital pedals and synthesizers bundle sensors, compute, and DSP behind a fixed price and a closed enclosure; Open-Pedal unbundles them, so a builder pays only for the parts their instrument actually needs and owns the whole stack from schematic to firmware.

2. Design

  • Hardware. Custom PCBs and 3D-printed components allow accessible swapping of components and microcontrollers to build custom devices — the same board family underlies a fuzz pedal, a granular sampler, or a standalone synth.
  • Software. A custom IDE forked from Arduino handles all required libraries and microcontroller profiles, so users can experiment with an interactive library of DSP while programming their devices, without toolchain setup.
  • Guides. Interactive build and DSP guides walk newcomers from a bare board to a playable device, treating each example program as a teaching object.

The intent is a full, comprehensive system built for future improvement — a platform others can extend rather than a one-off product.

3. Current Status

Design stage. Open-Pedal currently exists as the proposal above; a search of the EMGOR working archive found no dedicated Open-Pedal repository yet — its only written sources are the 2026–2027 papers planning document and the site's papers overview. The practice it formalizes, however, is already live across the EMGOR hardware planets: DIY PCB-based instruments such as the Pocket OpGorator (Daisy), 4-i-Gor (Teensy audio interface), and oFOOTS (Teensy foot controller) are effectively pre-Open-Pedal case studies, and their build files are public on this site.

4. Future Work

First milestones: define the core PCB family and its swappable sensor/compute modules; fork and strip the IDE; port one existing EMGOR device onto the framework as a reference build; then run the guides with first-time builders. Planned collaboration with Nina (MIT); Andrew, Ajay, and Todd possible. Target venues: NIME, TEI, ACM CHI, or ICMC.
