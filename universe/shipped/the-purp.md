# THE_PURP

**THE_PURP** is a synthesizer built for live performance — a Max for Live device that runs
inside Ableton Live and is mapped so that every knob on a hands-on MIDI controller lands
somewhere useful. It's the instrument this lab's performer actually plays from, not a demo
patch.

## What it solves

Off-the-shelf synths are built for someone else's controller layout and someone else's
workflow. THE_PURP exists because building the instrument yourself means the mapping, the
preset system, and the sound design can all be shaped around exactly how it gets played live —
and because a synth that's rebuilt from feedback after every gig ends up somewhere a stock
plugin never would.

## What's actually built

Finished and in active use — this is the single longest-running project in the lab. Roughly 45
numbered versions exist in the archive between 2023 and 2025; what's published here is the
current head of that lineage. It's a self-contained ("frozen") device with no external
plugin dependencies, built-in presets, and a multichannel audio engine underneath, ready to
drop onto any MIDI track.
