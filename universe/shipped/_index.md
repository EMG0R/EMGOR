# SHIPPED

Everything in this universe is a real project, but not everything is *finished*. This planet
is the short list — the things that got all the way to done: a paper submitted, a plugin
someone else can install, a Pi you can flash, a browser tab a stranger can open. If you only
have a few minutes, start here.

The rest of the lab — 21 Max for Live devices, 8 more papers in progress, a dozen hardware
builds mid-assembly — is real and documented on its own planets ([PAPERS](#/papers),
[M4L](#/m4l), [HARDWARE](#/hardware)). This planet just doesn't repeat the catalogue. It
picks the pieces worth judging on their own and says, plainly, what each one is, what it
replaced, and how much of it actually works right now.

## The seven

- **[NAM × Csound](#/shipped/nam-csound)** — a neural amp-modeling engine inside Csound.
  Finished: submitted to ICSC 2026, ships as a plugin and a Raspberry Pi guitar pedal.
- **[DemiurgeOS](#/shipped/demiurgeos)** — an audio-first operating system for the Raspberry
  Pi 5. Running: it's the platform under NEPTR on stage right now.
- **[OMNIPLEX](#/shipped/omniplex)** — one cable replacing four separate protocols for audio,
  video, MIDI, and lighting. In progress: the core Rust engine works; the product around it
  doesn't exist yet.
- **[NEPTR](#/shipped/neptr)** — a guitar effects computer that replaces the laptop on stage.
  Four generations built and performed with since 2023.
- **[THE_PURP](#/shipped/the-purp)** — the main performance synth. Finished, frozen, played
  live for two years across roughly 45 versions.
- **[neuralGrid](#/shipped/neuralgrid)** — a touch grid that redesigns its own layout mid-song
  without ever adding latency to the notes you're playing. Core loop working on hardware.
- **[CIESEN](#/shipped/ciesen)** — a generative ambient piece, playable this second, no
  install, in any modern browser tab.

## How to read "status" here

Three words appear across these pages and they mean specific things:

- **Finished** — submitted, shipped, or frozen. Nothing left to build for it to count.
- **Running / working** — in daily use right now, even if the feature list keeps growing.
- **In progress** — real, tested code that does not yet add up to a finished product.

Nothing here is rounded up. Where a project is closer to the third bucket than it looks, the
page says so.
