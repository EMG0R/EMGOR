# Pi Experiments

Before DEMIURGE was an OS it was a pile of questions: can a Pi be a drum machine? Can Csound run a piece headless on boot? These are the small satellites — self-contained experiments that proved the Pi could be an instrument, and exposed every problem (audio routing, boot config, hot-plug fragility) that DEMIURGE was later built to solve properly.

- **LILITH_PI** — a sample-based drum machine as a single Max patch, built for a Pi-adjacent hardware rig
- **csound on Pi** — headless Csound sketches: a generative rhythm driver and a nonlinear reverb piece
