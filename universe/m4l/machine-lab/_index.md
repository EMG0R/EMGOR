# Machine Lab (MachineLab4L)

A suite of Max for Live devices for composing on the robotic instruments of the CalArts Machine Lab — from anywhere. Each device ships with a sample library of its robot, so you hear the actual instrument while writing at home; connect to the lab's Skynet network and the same device handles the OSC communication to play the physical robot live. The top-left button on each device switches between local sampling and OSC mode.

Shared feature set across the suite:

- **Ableton MIDI integration** — each robot responds to its documented MIDI note range.
- **Generative mode** — hit **gen**, start the transport (space bar), then click the robot's on-screen representation to set per-note probability. **subd** sets subdivision relative to BPM, **chance** sets overall trigger probability.
- **Open patches** — unfreeze, take apart, have fun. If an edited device loses its audio files: unfreeze, drag all its samples anywhere into the device, re-freeze, save.

Six robots, six devices: BREAKBOT, GANA_PATI, TAMMY, LYDIA, MARIMBOT, MODULETTES.
