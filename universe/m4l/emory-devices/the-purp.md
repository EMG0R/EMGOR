# THE_PURP

The flagship. THE_PURP is EMGOR's main performance instrument — a Max for Live synth built for hands-on-controller playing, with a preset system and deep MIDI CC mapping so every knob on the desk lands somewhere useful. Multichannel (mc.) audio engine inside.

This is the longest-running project in the lab: roughly 45 versions between 2023 and 2025 live in the archive (`_OLD/purp/`, purp v1 through v3 eras). What ships here is the current head of that lineage.

## Use

Drop `THE_PURP.amxd` onto a MIDI track in Ableton Live (Suite / Max for Live required). Play it from a keyboard or map your controller's CCs — the device listens for control input natively. Presets are built in.

## Install

Drag the `.amxd` onto a MIDI track, or file it under your User Library. Frozen device — no external dependencies.
