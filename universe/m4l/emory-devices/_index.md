# Emory Devices

The curated personal device set. These are the tools that actually get used — performance synths, a granular ring-buffer mangler, a generative drum machine, motion-controlled effects, one-finger chord engines, and a Jitter visuals rig that runs from inside Ableton.

Some devices share abstractions from a common `dependancies/` folder in the source tree; every `.amxd` shipped here is frozen, so it carries what it needs. Install by dragging the `.amxd` onto an Ableton track.
