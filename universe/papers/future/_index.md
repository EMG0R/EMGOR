# 2027+

Work that is real but deferred. Nothing here is abandoned; it is all waiting on a season with room in it.

**[NeuralGrid](/papers/future/neuralgrid)** — mid-build. A grid, ribbon, and lidar controller whose model speaks a symbolic vocabulary borrowed from tabla *bols*, then translates it into sound through seven perceptual axes. First encoder working on hardware.

**[OMNIPLEX](/papers/future/omniplex)** — folding inward. One cable for audio, video, and control, implemented as a Rust workspace. The transport is being absorbed into DemiurgeOS as a feature; the standalone paper waits.

**[Open-Pedal](/papers/future/open-pedal)** — concept. An open-source, modular framework for building pedals and synths. The only thing on this planet that is still only an argument.

## On deferral

Most of what's here exists as working code or finished hardware. Being in the queue is a statement about attention, not about progress.
