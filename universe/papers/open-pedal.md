# Open-Pedal: An Accessible System for Modularly Creating Guitar Pedals and Synthesizers

**Status: PLANNED** — target venues: NIME, TEI, ACM CHI, ICMC.

## Abstract

The goal is to support disruption of the hold capitalism has on digital instruments and DSP through an open-source, DIY framework for creating powerful instruments and effect processors. The system's modularity means people pay only for the sensors and compute they need, while thoughtfully designed PCBs, software (an Arduino IDE fork with example programs and preinstalled libraries), and interactive guides provide a simple path to powerful digital interfaces.

## The argument

With coding, engineering, and technology becoming steadily more accessible, this framework bridges the gap between high-value electronics and the general population. Custom PCBs and 3D-printed components make swapping components and microcontrollers approachable; the custom IDE handles the libraries and microcontroller profiles so users can experiment with an interactive DSP library while programming their devices. A full, comprehensive system built for future improvement.
