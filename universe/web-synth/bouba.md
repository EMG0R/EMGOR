# BOUBA

The current build of the generative ambient piece, rewritten on the native Web Audio API with no WebAssembly. Pure sine voices, no vibrato or phasing, tuned to the harmonic series of C2 instead of equal temperament. Built to be as light as possible so it runs on an iPhone and keeps playing after the screen locks.

Six orbs: PITCH, KICK, WAVES, SIN, STORM, BIRD. Drag them.

The first build, written in ChucK and run through WebChucK, is kept as [BOUBA (legacy)](/web-synths/bouba-legacy).
