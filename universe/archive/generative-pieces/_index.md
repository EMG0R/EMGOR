# GENERATIVE PIECES

Pieces, not products. Each one started as a question — *what does this language want to sound like?* — and got answered in working code: a Csound study, an ambient self-player, C++ console-app generators, a generative FM piece in SuperCollider, and the virtual-modular alexthief patches. Everything here is real, everything ran, and the source is downloadable from its own planet.

## Orbits

- **CSOUND** — Nonlinear Daylight, a nonlinear reverb study, headless and generative
- **metaGOR** — a self-playing ambient Csound piece in one file
- **JUCE** — piGO and coolCLICKY, C++/JUCE console-app generators
- **SUPERCOLLIDER** — GEN_COLIDER, a generative FM piece across three versions
- **VCV** — the alexthief series of VCV Rack patches

The tools built *in* these same languages — EMGOR_SYNTH, EMGOR_FX, GEN_SEQUENCER, EMGOR_GENERATIVE_SAMPLR — moved to [PLUGINS](#/archive/m4l), where the other installable devices live.
