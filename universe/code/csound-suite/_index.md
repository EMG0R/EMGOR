# CSOUND SUITE

Csound instruments with Cabbage UIs. Csound is the oldest living computer-music language and it still compiles straight into plugins your DAW can load — two of these are built and in use as VST3/AU. Each instrument is its own planet; the `.csd` source for every one is downloadable there.

## Instruments

- **EMGOR_SYNTH v1.2** — 9-partial additive synth with routable LFO
- **EMGOR_FX v3** — stacked stereo FX rack, built as VST3
- **EMGOR_GENERATIVE_SAMPLR v3.2** — probabilistic 8-slot sampler, built as AU
- **metaGOR** — self-playing ambient piece in one file
- **GEN_SEQUENCER v1** — grid sequencer prototype

One `.csd` file is the whole instrument: UI layout, DSP, and MIDI handling in a single text document. That is the appeal.
