# WEB SYNTHS

The zero-install wing of the lab. These instruments are live on this site right now — no DAW, no download, no plugin scan. Three different routes to sound-in-a-tab:

- **CIESEN** — ChucK compiled to the browser via WebChuGL: generative ambient with interactive WebGPU visuals
- **NEPTR** — a Max/RNBO patch exported to WebAssembly, with keyboard, sliders, and presets
- **BMO** — a pure-WebGL shader scene: lava noise bending around a black hole

Each leaf links straight to the live page. CIESEN's ChucK source is downloadable from its planet.
