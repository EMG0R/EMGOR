Read **[MD/DEMIURGE.md](MD/DEMIURGE.md)** — the system orientation: the map of

Then read **[demiurge/local/device.md](demiurge/local/device.md)** — *who this
node is*. `MD/DEMIURGE.md` (above) is the parent class; `device.md` is this box's
child layer, and **the device layer wins**. Every Demiurge node carries its own
`demiurge/local/device.md` in the local bucket — read yours to know which device
you are before acting. On this node you are what that file names.

This file is a pointer on purpose. `CLAUDE.md`, `GEMINI.md` and `AGENTS.md`
all point at the same document so the three agent backends cannot drift apart.
Edit `MD/DEMIURGE.md`, not this.
