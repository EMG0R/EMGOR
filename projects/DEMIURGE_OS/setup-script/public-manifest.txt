# public-manifest.txt -- the per-FILE allowlist for the public DEMIURGE export.
#
# RULE: NOTHING SHIPS BECAUSE OF THE DIRECTORY IT SITS IN.
# Every path below was opened (or, for small config/units, read in full or
# scanned line by line for instrument/host terms) and judged on CONTENT.
# A new file in an already-listed directory does NOT ship. Adding a path
# here is a deliberate act: open the file, read it, then add one line.
# There are no directory entries and no globs, except where a comment says
# a whole directory is provably generic (none currently).
#
# Why this exists: the old manifest listed whole directories. A personal
# file (docs/neptr-param-migration.md -- the owner's NEPTR menu/CC layout)
# was dropped into docs/ and rode out to a public repo. A directory-level
# allowlist is not an allowlist.
#
# THE WALL
#   PUBLIC  = the SYSTEM: what a stranger needs to install and run DEMIURGE
#             on their own Pi.
#   PRIVATE = the INSTANCE: the owner's machines, home network, and his
#             personal instrument NEPTR (control layout, menus, CC maps,
#             effect params, patches, calibration), his hardware (PMOR,
#             hyperGuitar, DUODECIMUS), incidents, agent handoffs.
#   Ambiguous -> EXCLUDED. Excluding costs a feature; including costs his
#   instrument design. Not symmetric.
#
# FORMAT: one repo-relative path per line. '#' lines are comments. Sections
# marked HELD are commented out on purpose: they are NOT exported until the
# owner makes the call described next to them.
#
# Marker NAME-ONLY: file contains the bare word NEPTR (or a service/path name
# like neptr-ui, /dev/shm/neptr-state) in a comment or default, but no
# layout, CC map, param, patch or calibration. Shipped on that basis; the
# owner may veto by deleting the line. (Public publish-public.sh does NOT
# scrub the word 'neptr'; it only scrubs hostnames/IPs/email.)
#
# publish-public.sh CONSUMES THIS FILE: it ships exactly the uncommented paths
# below (must exist, be git-tracked, be a regular file) and nothing else. Its
# sanitizer/verify pass catches GOR_CAVE (case-insensitive), MAC addresses and the
# Focusrite serial as a second line of defense; those files are still excluded
# here, not relied on to be sanitized. The script itself and this manifest never
# ship (private-side tooling).
